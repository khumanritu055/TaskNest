# TaskNest — Basic Student Task Manager
A beginner-friendly, multi-page student task manager built with HTML, CSS and vanilla JavaScript. No Node.js, Express.js, database, or installation required.

## Run
1. Extract this folder.
2. Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.
3. Register a demo account, log in, and use Dashboard / My Tasks.
4. Logout returns to the home page.

## Pages
- `index.html` — Home / landing page
- `register.html` — Create account
- `login.html` — Login
- `dashboard.html` — Progress overview (login required)
- `tasks.html` — Add, edit, complete, search, filter and delete tasks (login required)
- `about.html` — Project information
- `contact.html` — Demo contact form

## Storage and limitation
Demo accounts, tasks and contact messages use browser `localStorage`. This is front-end-only authentication, not secure production authentication. Data remains in the same browser profile and can be cleared from browser settings. Do not use a real password or sensitive information.

## Portfolio description
TaskNest is a responsive student task management website that helps students organize assignments, study activities and deadlines. It demonstrates multi-page navigation, form validation, browser storage, task CRUD operations, filtering and dashboard statistics using HTML, CSS and JavaScript.
