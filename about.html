ABOUT TASKNEST

Study smarter,
not harder.

TaskNest is a simple student task manager concept designed to help learners organize academic responsibilities without complicated tools.

🎯

Our purpose

Help students remember deadlines, build productive habits and stay aware of their progress.

🧩

Simple by design

Clear pages and easy controls make it suitable for everyday student use.

🔒

Local demo storage

This version stores demo data in your browser using localStorage, with no database or server.

Project objectives

  • Provide a simple registration and login interface.
  • Allow students to create, edit, search and delete tasks.
  • Display task progress through a dashboard.
  • Practice HTML, CSS and JavaScript page navigation.
